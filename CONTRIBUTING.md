# Contributing — keep it useful, keep it honest

This repo is not code. It's free lab survival docs.

Good contributions:
- Another instrument cleaning note (Maccor, Arbin, Landt) with a tiny sample CSV
- A formulation constraint example that broke your DOE
- A better EIS pitfall with a plot

Rules:
1. No proprietary data. Anonymize chemistry if needed.
2. No fake numbers as real. Label DEMO if synthetic.
3. Small PRs. One template or one guide at a time.
4. No sales pitches. Link to your tool once at the bottom max.

Open an issue `LAB-TRY: <instrument>` if you want free Pro to test the hosted version at https://matflow.celaron.com.
